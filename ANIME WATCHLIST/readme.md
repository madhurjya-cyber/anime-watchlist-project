# Anime Watchlist Management System

## Overview

A Python and MySQL based Anime Watchlist Management System.

This project allows users to:

- Add anime
- View anime
- Track watch status
- Update ratings
- Delete watchlist entries
- Analyze watchlist data using Pandas
- Generate visualizations using Matplotlib

---

## Technologies Used

- Python
- MySQL
- Pandas
- Matplotlib

---

## Database Tables

1. Genre
2. User
3. Anime
4. Watchlist

---

## Features

### CRUD Operations

- Create Anime
- Read Anime
- Update Status
- Update Rating
- Delete Entries

### Analytics

- Average Rating
- Highest Rating
- Lowest Rating
- Status Distribution

### Visualizations

- Anime Rating Graph
- Watch Status Graph
